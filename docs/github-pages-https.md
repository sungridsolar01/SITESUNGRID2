# HTTPS no GitHub Pages

O redirecionamento HTTP → HTTPS é uma configuração da hospedagem, não do código do site.

No repositório `sungridsolar01/SITESUNGRID2`:

1. Abra **Settings → Pages**.
2. Confirme o domínio personalizado `sungridsolar.site`.
3. Marque **Enforce HTTPS**.
4. Teste `http://sungridsolar.site/` e confirme o redirecionamento para `https://sungridsolar.site/`.

Não adicionar redirecionamento JavaScript ou meta refresh ao HTML.
